# SlayTrip ⚡ — Slaying the Itinerary

> **GenZ-first Travel Planning Engine** built with **FastAPI + Vanilla JS**

## Features
- 🗺️ **Dynamic Trip Builder** — 3-step wizard with destination, preferences & constraints
- 🎨 **4 Dynamic Themes** — changes randomly on every page load
- 🏛️ **Role-Based Auth** — Customer, Provider, Manager login screens
- 🇮🇳 **India-first Destinations** — Goa, Hyderabad, Jaipur, Leh + global spots
- 💰 **Budget Engine** — INR cost estimates for activities, hotels, transport
- 🛡️ **Security Center** — Digital Vault, Device Management, Privacy Mode

## Tech Stack
- **Backend**: Python 3.11 + FastAPI + Uvicorn
- **Frontend**: Vanilla HTML5 / CSS3 / JavaScript (ES6+)
- **Deployment**: Google Cloud Run + Docker

## Local Development

```bash
# Install backend dependencies
pip install -r backend/requirements.txt

# Run backend (serves frontend too)
python backend/main.py

# Open in browser
open http://localhost:8005
```
